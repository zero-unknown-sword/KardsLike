# KardsLike

一款非商业的同人卡牌游戏，灵感来自游戏《KARDS》（1939 Games，冰岛）。
A non-commercial fan-made card game inspired by the game KARDS.

## 目录结构

- `kardslike/`：游戏源代码
- `kardsliker/`：KardsLiker mod 编辑器
  - `kardsliker/forge/`：KARDS DIY 卡面制作器
- `releases`：可运行版本通过 GitHub Releases 发布，不纳入 Git 仓库

## 启动

双击：

```text
kardsliker/启动KardsLiker.pyw
```

即可打开本地 KardsLiker 窗口。

需要控制台日志时使用：

```text
kardsliker/启动KardsLiker.cmd
```

# KardsLike

一款非商业的同人卡牌游戏，灵感来自游戏《KARDS》（1939 Games，冰岛）。
A non-commercial fan-made card game inspired by the game KARDS.

## 目录结构

- `code/`：存放源代码
- `game/`：存放各版本的 exe 文件，`recent/` 为最新版
